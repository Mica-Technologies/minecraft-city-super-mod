# Blocks to Revisit

Blocks removed from the mod that we may want back one day. Each was removed because its model was
not our own work, not because the idea was bad, so any of them can return with a model we make
ourselves (a generator in `dev-env-utils/scripts/`, like the rest of the mod's models).

Registry names are listed so a returning block can reuse its old name: a world that still holds
one would then pick it back up.
